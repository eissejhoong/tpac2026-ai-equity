# AI & Equity · TPAC 2026

A 5-minute talk for the W3C TPAC 2026 AI & Society mini-workshop, given by Jessie Hoong on behalf of the [W3C Equity Community Group](https://www.w3.org/community/equity/).

**View the slides:** https://eissejhoong.github.io/tpac2026-ai-equity/

## Using the deck

| Key | Action |
|---|---|
| Right arrow, Space, Page Down | Next slide |
| Left arrow, Page Up | Previous slide |
| Home / End | First / last slide |
| N | Show or hide speaker notes |
| F | Full screen |
| P (on slide 3) | Play or pause the audio clip |

The slide number is in the address, so `#3` opens slide 3.

## Accessibility

- Every text colour meets WCAG 1.4.6 Contrast (Enhanced), 7:1 or higher.
- Works with keyboard only. Slide changes are announced to screen readers.
- The audio clip on slide 3 is a real button. Its words are shown on the slide as a caption.
- Every link shows its web address, so people can type it in.
